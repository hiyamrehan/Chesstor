\chapter{Conclusion}
Chesstor targets state integrity in physical chess tracking. At the mid stage the core module is implemented,
unit-tested, and evaluated on simulated streams, where temporal confirmation plus legal-move constraints clearly
outperform frame-only and single-mechanism baselines, while stress tests exposed a genuine weakness to persistent
errors that we partly mitigated and will study with real boards. The team's React interface is connected to the core and packaged for phones, but has not been run on a real camera. The principal
gaps are real-board data, real-phone testing and device latency. FYP-2 prioritises these, then the tutor features, robustness evaluation and an acceptance study.
